# 🎣 Ocean Hook - Game Plan

## Game Idea

Ocean Hook is a browser-based fishing arcade game where the player controls a fishing rod to catch sea creatures. The goal is to collect points by catching good creatures while avoiding dangerous ones.

## Game Objective

The player must reach 15 points before losing all 3 lives.

## Core Gameplay

* The player aims the fishing rod using the mouse.
* Clicking launches the hook into the water.
* The hook catches moving sea creatures.
* Good creatures increase the score.
* Bad creatures reduce the player's lives.

## Game Features

* Animated swimming sea creatures using sprite sheets.
* Fishing rod rotation and hook movement.
* Collision detection between the hook and creatures.
* Score and lives tracking.
* Start menu and game over screen.
* Win and lose conditions.

## Game Assets

* Ocean background images.
* Fishing rod and hook graphics.
* Fish and sea creature sprite sheets.

## Technologies Planned

* HTML5 for structure.
* CSS3 for styling and animations.
* Vanilla JavaScript for game logic and interactions.
* GitHub Pages for deployment.

## Future Improvements

* Add sound effects and background music.
* Add mobile touch controls.
* Add more types of sea creatures.
* Add difficulty levels.
* Add a high-score system.
